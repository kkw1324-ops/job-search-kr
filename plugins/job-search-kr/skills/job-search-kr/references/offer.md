# 오퍼 검토와 연봉 협상

결과는 `applications/<회사>-<직무>/오퍼검토.md`에 저장한다.

## 원칙

- 결정을 대신 내리지 않는다. 계약서 검토 결과에는 "서명해도 안전하다" 같은 판정, 점수, 신호등 표시를 쓰지 않고, 조항별 태그와 두 목록(3장)으로 낸다. 6장의 오퍼 비교 점수는 판단 재료로 쓴다.
- 계약서와 처우 협의서 내용은 검색어에 넣지 않는다(SKILL.md 규칙 7).
- 오퍼를 받으면 먼저 프로필 「이직 대전제」, 「지원 대상과 조건」, 「딜브레이커」와 견줘 어긋나는 곳을 적는다. 판단은 사용자가 한다. 딜브레이커가 비어 있으면 [profile.md](profile.md) 「목표」대로 먼저 받는다.
- 세금·실수령액을 기억으로 계산하지 않는다. 국세청 간이세액표나 사용자가 쓰는 계산기 결과를 받아 쓰고, 추정이면 추정이라고 쓴다.

## 1. 한국 근로 조건 표

법령 확인일: 2026-09-27(국가법령정보센터 law.go.kr). 다시 확인하는 기준은 [kr-law.md](kr-law.md) 첫머리를 따른다.

| 항목 | 확인할 것 |
|---|---|
| 정규직 | 경력자의 기본값. 아니면 이유를 묻는다 |
| 계약직 | 기간, 연장·정규직 전환 조건과 실적, 종료 위험. 2년을 넘겨 쓰면 기간의 정함이 없는 근로자로 본다. 예외 사유가 있다(기간제법 제4조) |
| 수습 기간 | 보통 3개월. 급여 100% 지급 여부, 평가 기준, 수습 종료 시 해고 조건. 최저임금 감액은 1년 이상 계약이고 수습 3개월 이내일 때 최저임금의 90%까지다. 고시된 단순노무 직종은 감액할 수 없다(최저임금법 제5조 제2항, 같은 법 시행령 제3조) |
| 포괄임금제 | 연장·야간·휴일 수당을 연봉에 포함. 고정 연장근로 시간, 실제 야근 문화, 초과분 지급 여부. 실제 연장근로가 약정 시간을 넘을 때 차액을 받을 수 있는지는 노무사 질문으로 적는다 |
| 퇴직금 | 계속 근로 1년 이상이고 4주 평균 주 15시간 이상이면 퇴직금이나 퇴직연금(DB·DC) 같은 퇴직급여 대상이다(퇴직급여법 제4조 제1항, 제2조 제6호). 제시 연봉에 퇴직금이 포함됐는지 따로 확인. 포함이면 DC형 적립금을 총액에 넣어 표시한 것인지, 매달 나눠 주는 것인지 묻는다. 매달 나눠 주는 약정의 효력은 노무사 질문으로 적는다 |
| 4대 보험 | 국민연금·건강·고용·산재. 기본 조건. 프리랜서·위촉 계약이면 없을 수 있음. 계약 이름과 달리 출퇴근·업무 지시를 받는다면 근로자로 볼 수 있는지 노무사 질문으로 적는다 |
| 사업장 규모 | 상시 4명 이하 사업장에는 근로기준법 일부만 적용된다(근로기준법 제11조 제2항, 같은 법 시행령 제7조 별표 1). 상시 근로자 수를 묻는다. 5인 미만이면 연차·가산수당·해고 제한이 적용되는지 노무사 질문으로 적는다 |
| 고용 주체 | 브랜드와 실제 고용 법인(계열사·자회사·파견 업체)이 다르면 고용 법인 기준으로 본다. 외국계가 한국 법인 없이 대리 고용 업체(EOR)나 용역 계약으로 고용하면 4대 보험과 퇴직금을 누가 책임지는지 묻는다 |
| 세전 연봉 | 협상 기준은 보통 세전. 실수령과 구분 |
| 성과급·인센티브 | 산정 기준, 최근 몇 년 지급 이력, 재직 조건, 회사 재량 여부 |
| 스톡옵션·RSU | 수량, 행사가, 베스팅 일정, 퇴사 시 처리, 현금화 가능성 |
| 사이닝 보너스 | 의무 재직 기간과 반환 조건 |
| 연차·휴가 | 법정 기준 이상인지(사업장 규모 행 참고), 실제 사용 문화 |
| 식대·복지포인트 | 총보상 비교에 포함 |
| 재택 | "가능"과 "상시 가능"은 다르다. 출근 빈도 |
| 하이브리드 | 주 몇 회 출근, 팀 출근일, 근무 지역 제한 |
| 프리랜서·개인사업자 | 용역 계약. 단가, 세금(3.3%), 보험, 종료 위험을 따로 계산. 세율 값은 쓰는 시점에 국세청 등 출처에서 확인한다 |

## 2. 보상 분해

1. 표 첫 행은 회사가 제시한 원문 금액이다. 시장 자료와 섞지 않는다.
2. 나눈다: 보장 기본급 / 고정 수당 / 변동 급여(성과급) / 비현금(주식, 복지). 매달 확실히 받는 현금을 한 줄로 따로 적는다.
3. "포괄", "최대", "수당 포함", "퇴직금 포함" 같은 표현은 기본급이 낮을 수 있다는 신호로 표시한다.
4. 인사 담당자에게 확인할 질문 3~6개를 붙인다. 예: 계약서에 적힐 기본급 / 제시 금액에 수당·성과급·퇴직금이 들었는지 / 수습 기간 감액 여부 / 보장 항목과 회사 재량 항목.
5. 총액이 비슷하면 기본급 비중을 비교한다. 기본급이 높은 쪽이 다음 해 인상에 유리할 수 있다.

## 3. 계약서 검토

1. 구두로 제안을 받으면 처우 협의서나 오퍼 레터를 서면으로 요청한다. 검토할 시간과 회신 기한을 묻는다. 그 자리에서 수락하지 않는다.
2. 사용자가 계약서·처우 협의서 내용을 붙여넣으면, 조항 목록과 첫 조항을 되읽어 제대로 받았는지 확인받는다. 글자가 깨졌거나 일부만 읽혔으면 멈추고 다시 받는다.
3. 구두·메일로 들은 약속을 모은다: 누가, 언제, 어떤 매체로.
4. 계약서가 참조하는 문서(취업규칙, 스톡옵션 계약서 등)가 있으면 받아 달라고 한다.
5. 조항마다: 원문 인용 + 쉬운 설명 + 태그 하나 이상(흔히 협상됨 / 노무사 확인 / 들은 것과 같음 / 들은 것과 다름 / 표준). 빠진 항목은 따로 모은다.
6. 계약서 조건을 평가 보고서의 연봉·근무지·직급, 프로필의 최저선과 맞춰 본다. 다른 곳은 양쪽 원문을 함께 적는다.

확인할 열 가지:
1. 보상: 기본급, 고정 연장근로, 성과급 조건과 회사 재량 문구
2. 주식: 베스팅, 클리프, 행사 기간, 퇴사 시 처리
3. 계약 형태·기간·수습·해고 사유, 퇴사 통보 기간(양쪽)
4. 경업금지·전직금지·고객과 직원 유인 금지: 기간, 범위, 보상 유무
5. 직무발명·지식재산: 입사 전 작업과 개인 프로젝트 예외
6. 반환 조항: 사이닝 보너스, 교육비, 이사비, 의무 재직 기간
7. 근무 시간·장소·포괄임금·재택
8. 연차·휴가·복리후생
9. 퇴직금 포함 여부
10. 들은 약속이 서면에 있는지, 회사가 일방적으로 바꿀 수 있는 조항, 조건부 조항, 오퍼 회신 기한

결과물은 두 목록이다: 노무사·변호사에게 물을 질문 / 회사에 꺼낼 항목. 회사에 꺼낼 항목은 질문 형태로 쓰고, 서명 전에 꺼낸다. 회신 메일 초안은 요청이 있을 때만 쓴다. 메일에는 회사에 꺼낼 항목 목록에 있는 것만 넣고 법 조항을 들지 않는다. 메일은 초안만 쓴다(SKILL.md 규칙 5).
결과 끝에 적는다: "AI가 만든 읽기 보조이며 법률 자문이 아니다. 빠뜨리거나 잘못 읽은 조항이 있을 수 있다. 서명 여부는 사용자가 정한다."

## 4. 연봉 자료 조사

- 조사한 연봉 자료는 `applications/<회사>-<직무>/연봉자료.md`에 저장한다.
- 출처: 원티드 연봉 정보, 잡플래닛, 블라인드, 리멤버, 사업보고서의 1인 평균 급여(상장사), 국민연금 기반 추정 서비스. 값은 쓰는 시점에 각 출처에서 확인한다.
- 로그인이 필요한 곳은 사용자가 Chrome(Claude in Chrome)에서 로그인한 뒤 메인 대화가 읽은 값이나 사용자가 붙여넣은 값만 쓴다.
- 출처마다 치우침이 있다: 국민연금 가입 기반 추정은 고연봉 구간을 낮게 잡을 수 있다. 일부 연봉 정보에는 상여·성과급이 빠진다. 회사 공시는 전 직원 평균이라 직무 차이가 가려진다. 같은 회사도 출처끼리 크게 다를 수 있으니 한 출처만 믿지 않고 여러 곳에서 맞춰 본다. 이렇게 여러 출처로 맞춰 본 범위를 이 글에서 「맞춘 자료」라고 부른다.
- 연봉 범위는 기술보다 직함·직급이 정하는 경우가 많다. 제시받은 직급을 먼저 확인한다.

## 5. 협상 준비

협상은 최종 합격 뒤, 서명 전에 한다. 신입 공채처럼 초봉이 정해진 곳인지 먼저 확인한다. 정해진 곳이면 회사에 물을 질문을 준비한다: 경력 인정(호봉·연차), 직급, 입사일, 연봉 증빙 서류가 필요한지. 지원 구분은 `전략.md` 「내 위치」에서 읽는다.

세 숫자를 정한다.
- **최저선**: 사용자가 정한 거절선(프로필 「지원 대상과 조건」의 최저선). 이 아래의 제시는 거절 후보로 알리고 결정은 사용자가 한다. 프로필에 없으면 먼저 받는다. 회사에 말하는 방법은 「희망 연봉 답변」을 따른다.
- **목표**: 맞춘 자료(「4. 연봉 자료 조사」)의 시장 범위 중상단. 범위의 어디에 둘지는 올리는 요인(희소 기술, 성과 기록, 다른 오퍼, 추천 입사)과 낮추는 요인(직무 전환, 요건 부족)을 적어 보고 정한다.
- **첫 제시**: 목표보다 조금 높게.

원칙:
- 시장가 아래 금액을 권하지 않는다.
- 면접에서 이미 말한 숫자(면접 복기 기록), 지원 화면에 넣은 희망연봉([submit.md](submit.md) 「순서」의 제출 전 요약 단계), 구직 사이트 프로필의 값(프로필 「구직 사이트 프로필 현황」)과 어긋나지 않게 한다.
- 현재 연봉을 물으면 먼저 희망 범위로 답한다. 밝혀야 하면 사실대로 말한다. 원천징수영수증으로 확인하는 회사가 있다.
- 기본급이 막히면 다른 항목으로: 사이닝 보너스, 직급, 입사일, 재택, 교육비, 연차, 첫 평가 시점.
- 다른 오퍼는 사실이고 실제로 옮길 준비가 됐을 때만 언급한다.
- 직급이 낮게 제시되면: 처우가 공정한지 보고, 첫 평가 시점과 승진 기준을 서면으로 요청한다.
- 구두로 합의한 기본급·성과급 조건·복리후생·적용 시점·다음 평가일을 서면으로 받는다. 받은 뒤 세후 실수령으로 다시 확인한다.

### 희망 연봉 답변

회사가 희망 연봉을 물으면 아래 표대로 답한다. 면접에서도 같다.

| 상황 | 답 |
|---|---|
| 맞춘 자료(「4. 연봉 자료 조사」)가 있거나 다른 오퍼가 있음 | 세전 범위로 답한다(아래 말하기 예 1) |
| 자료가 약하고 다른 오퍼가 없음 | 회사의 책정 범위를 먼저 묻는다. 회사가 범위를 말하지 않고 숫자를 요구하면 예 1처럼 범위로 답한다 |
| 어느 경우든 | 최저선을 먼저 말하지 않는다 |

한국어 말하기 예:
1. 희망 연봉을 물을 때: "현재 시장과 제 경력을 기준으로 세전 ○○○○만~○○○○만원 수준을 생각하고 있습니다. 성과급과 복리후생을 포함한 전체 조건에 따라 조율할 수 있습니다."
2. 지역·회사 규모를 이유로 낮출 때: 직무의 시장 범위 자료를 근거로, 조건이 아니라 역할의 가치로 이야기한다.
3. 목표보다 낮은 제시를 받았을 때: "제안 감사합니다. 비교하고 있는 수준은 ○○○○만원 선이고, 이유는 ○○입니다. ○○○○만원까지 맞춰 주실 수 있을까요?" 그 금액이면 실제로 수락할 때만 "○○○○만원이면 바로 결정할 수 있습니다"를 쓴다.
4. 구성을 확인할 때: 기본급 / 성과급 / 주식 / 사이닝을 항목별로 나눠 달라고 하고, 성과급은 최근 지급 이력을 묻는다.

## 6. 여러 오퍼 비교

기본 가중치: 목표 적합 25 / 요건 충족과 성장 25 / 직급 15 / 보상 15 / 일하는 방식 10 / 회사 상태 10. 사용자 우선순위에 맞게 가중치를 바꾸고, 바꾼 이유를 적는다. 점수는 판단 재료다.
보상은 확정 보상과 변동 보상(성과급·주식)을 따로 계산한다. 변동 보상을 확정 금액처럼 더하지 않는다.
