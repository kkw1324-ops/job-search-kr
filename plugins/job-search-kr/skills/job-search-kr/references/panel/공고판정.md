# 공고 판정 재확인 기준

이 역할은 공고 거르기([collect.md](../collect.md) 「거를 때」)의 판정을 메인 대화와 따로 다시 판정해 어긋남을 찾는다. 서류를 검토하지 않으므로 서류 검토의 H·A 판정 형식과 [공통.md](공통.md)의 정의를 쓰지 않는다. 에이전트 [job-reviewer.md](../../../../agents/job-reviewer.md)가 위임 프롬프트의 역할 이름 「공고 판정 재확인」으로 이 파일을 읽는다.

## 받는 것

- 공고 원문 파일(`postings/`)
- 프로필 「목표」(검색 직함, 인접 직무, 목표 산업군)와 자격조건 판정에 필요한 줄(학력, 경력 연수, 자격증·어학)
- [evaluate.md](../evaluate.md) 「3. 관문」의 관문 규칙
- 다시 판정할 공고 목록: 제외 사유별로 몇 건씩 뽑은 공고 번호. 메인의 판정과 근거는 받지 않는다.

이 밖의 자료(프로필의 나머지 부분, 메인 대화의 맥락)는 받지 않고, 받은 자료 밖의 정보로 판정하지 않는다.

## 하는 일

공고마다 원문만 읽고 관문 규칙으로 판정을 낸다: 후보, 보류(사유), 어학 대기, 제외(관문과 근거 값). 근거는 원문 줄이나 받은 프로필 줄로 적는다. 확실하지 않으면 제외하지 않고 보류로 내고 사유를 적는다. 직원 수와 규모는 조회 결과가 없으므로 판정하지 않고 「판정 안 함(조회 필요)」으로 적는다. 원문에서 읽을 수 없는 값(`[판독 불가]`)은 짐작하지 않는다.

## 돌려줄 것

| 공고 번호 | 재판정 | 근거(원문 줄 또는 프로필 줄) |
|---|---|---|

메인 대화가 이 표를 자기 판정과 맞춰 본다. 어긋난 공고는 원인이 관문 규칙의 모호함인지 프로필 「목표」의 검색 직함 누락인지 메인이 한 줄로 적어 규칙이나 프로필을 고치는 재료로 쓴다. 어긋남의 개수로 통과 여부를 정하지 않는다.
