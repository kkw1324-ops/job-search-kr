# 영문 CV, 커버레터, LinkedIn

외국계와 해외 기업 지원용이다. 공통 규칙(사실 대조, 수치, 경력 줄, 금지 표현, 키워드 반영률)은 [writing-common.md](writing-common.md)(바꿔 써도 되는 범위는 「사실 대조」), ATS 규칙은 [resume-kr.md](resume-kr.md)를 따른다.

## 국문 이력서와 다른 점

| 항목 | 국문 이력서 | 영문 CV |
|---|---|---|
| 사진, 생년월일, 성별, 혼인 여부, 병역 | 양식이 요구하면 씀 | 쓰지 않는다 |
| 주소, 연락처 | 양식대로 | 주소는 도시까지만, 전화번호는 하나. 머리글·바닥글이 아닌 본문 첫 줄에 둔다 |
| 분량 | 1~2쪽(경력자 2~3쪽) | 경력 0~5년 1쪽, 5~15년 1~2쪽, 15년 이상 2쪽 |
| 날짜 | YYYY.MM | Mon YYYY (예: Mar 2023) |
| 절 제목 | 학력, 경력, 자격증 | Summary, Work Experience, Education, Skills, Certifications 같은 표준 이름. 꾸민 제목은 ATS가 인식하지 못할 수 있다 |
| 문장 | 명사형 종결 | 동사 과거형으로 시작, 주어 생략 |
| 학력 위치 | 앞쪽 | 경력으로 내면 뒤쪽(지원 구분은 `전략.md` 「내 위치」) |
| 어학 | 시험, 점수, 응시일 | 만료된 점수와 응시 예정 시험은 사용자가 확인한 것만 쓴다(만료 규칙은 resume-kr.md 「이력서 항목」 5번). 근거는 실제 영어 업무(메일 상대, 다룬 내용) |

한국 회사명·직함은 공식 영문명을 쓴다. 공식 영문명이 없으면 로마자 표기 뒤에 괄호로 업종을 설명한다. 직함은 뜻이 같은 영어로 옮기되 레벨을 올리지 않는다(대리 → 보통 Associate 또는 Specialist, 회사 내부 체계를 사용자에게 확인).

## 공고에 맞추기

1. 공고에서 키워드를 하드 스킬, 소프트 스킬, 업계 용어로 나눠 뽑는다.
2. 배치는 writing-common.md 「키워드 반영률」(경력 줄 먼저, Summary는 대표 성과에 닿는 키워드만)을 따른다. 영문 차이: Skills는 공고 표기 그대로(사실일 때만).
3. Summary를 다시 쓴다: 목표 직무 + 연차 + 가장 강한 역량 + 대표 성과. 업종을 바꾸는 지원이면 resume-kr.md 「상단 요약」의 연결 문장처럼 쓴다.
4. Skills도 공고 요건 순서로 다시 놓는다.
5. 나머지(격차 분류, 채용담당자 의심, 사실 대조, 보고)는 resume-kr.md 「공고에 맞추는 순서」 2·3·5·6·7을 따른다.

## 문장 공식

- **XYZ**: Accomplished X as measured by Y by doing Z.
- **CAR**: Challenge → Action → Result.
- 한 줄은 1~2행. 줄 수는 writing-common.md 「줄 수」.
- 수치 다섯 가지: 금액, 비율, 시간, 규모, 전후 비교. 수치 확인과 추산은 writing-common.md 「수치」·「추산값 추천」을 따른다. 결과를 모르면 투입 규모(처리 건수, 인터뷰 수)를 묻는다.
- 영어 금지 표현은 writing-common.md 「금지 표현」의 영어 목록을 따른다.

## 숨은 경험 끌어내기

공고 요건에 대응할 경험이 프로필에 없을 때 묻는다. 없다고 하면 지어내지 않는다.

1. 요건마다 먼저 묻는다: "공고가 X를 요구합니다. X나 비슷한 일을 해 본 적이 있나요?" 그다음 "최근 6개월 동안 이력서에 없는 일 중 비슷한 것이 있었나요?"
2. 답에 따라 나눈다: 직접 경험 / 간접 경험(옆에서 봤거나 일부 참여) / 인접 기술 / 개인 프로젝트 / 없음.
3. 없음이면 작은 개선, 멘토링, 문서화 같은 작은 사례를 한 번 더 묻는다.
4. 두세 번 물어도 없으면 넘어간다. `전략.md` 「덮을 것」에 그 격차의 답할 방향이 있으면 따르고, 없을 때만 선택지를 준다: 커버레터에서 솔직히 언급 / 그 요건은 비워 둠 / 학습 계획으로 설명.

쓸 때: 간접 경험은 맡은 지원 역할 그대로 쓴다(예: "Supported the X rollout by preparing test data"). 인접 기술은 실제로 쓴 기술 이름 그대로 관련 경험으로 쓴다. 공고의 기술을 직접 쓴 것처럼 바꾸지 않는다.

## 커버레터

- 공고가 없으면 쓰지 않는다.
- 250~400단어, 네 문단. 1쪽을 넘기지 않는다.
  1. 도입 2문장: 지원 직무와, 이 회사에 대한 구체적 이유 하나
  2. 강점 매칭: 공고의 핵심 요구 2~3개와 내 성과(프로필 원문 수치)
  3. 추가 가치와 격차: 회사가 풀려는 문제, 내가 할 수 있는 일, 입사하면 처음 할 일. 격차는 아래 「격차」 줄대로 쓴다
  4. 마무리: 대화를 요청하는 한 문장
- 쓰기 전에 사용자에게 묻는다: 왜 이 회사인가(essay-kr.md 「지원동기」와 `전략.md` 「앞세울 것」을 따른다), 어떤 문제를 풀 수 있는가, 입사하면 처음 무엇부터 할 것인가, 어조.
- 격차(도메인, 입사 가능일, 언어 수준, 직함 차이)는 `전략.md` 「덮을 것」의 답할 방향을 먼저 따른다. 거기에 없는 격차만 사용자에게 묻는다: 짧게 직접 언급 / 언급하지 않음 / 사용자가 말하는 각도로 씀.
- 인사말: 받는 사람 이름을 알면 "Dear [이름]", 모르면 "Dear Hiring Manager"나 "Dear [회사] Recruiting Team". "To Whom It May Concern"은 쓰지 않는다.
- 피할 도입은 writing-common.md 「금지 표현」을 따른다. 피할 마무리: "Please find my resume attached", "I am available at your convenience".
- 시험: 이 문장이 다른 회사 커버레터에 그대로 들어가도 되면 다시 쓴다.
- 대화에 초안을 먼저 보이고 승인 뒤 파일로 만든다.

## LinkedIn

- 헤드라인(220자): [직무] | [전문 분야] | [주는 가치]
- About(2600자 중 1500~2000자 권장): 첫 300자 안에 핵심. 더 보기를 누르기 전에 보이는 부분이다.
- Skills는 50개까지, 공고에 자주 나오는 것 위주.
- 이력서와 날짜·직함·회사명이 같아야 한다.
- 로그인이 필요하므로 직접 고치지 않는다. 문구만 만들어 주고 사용자가 붙여넣는다.
- 재직 중이면 구직 중 표시(Open to Work)를 채용담당자에게만 보이게 설정하라고 안내한다. 전체 공개로 두면 프로필 사진에 표시가 붙어 누구나 본다.

## 파일로 만들기

영문 CV와 커버레터도 [forms.md](forms.md)의 방법으로 Word 파일을 만든다. 영문 문서는 `work/doc.json`의 언어를 `en`으로 둔다. 파일 이름은 `Gildong_Hong_CV`, `Gildong_Hong_Cover_Letter`처럼 이름과 문서 종류로 쓴다.

파일을 만들기 전에 확인한다.
- 회사명과 직무명이 처음부터 끝까지 이 지원의 것인가. 다른 회사용 문장이 남아 있지 않은가
- 커버레터 날짜가 오늘인가
- 회사가 요청한 서류만 내라고 사용자에게 알린다
